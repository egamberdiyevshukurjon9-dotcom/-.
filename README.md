## Жарвис — ҳолограф овозли ёрдамчи

- `jarvis/index.html` — асосий дастур (битта файл, ташқи кутубхонасиз). Chrome ёки Edge'да очинг.
- `jarvis-classic/` — оддий версия.
- `fan/` — 3D вентилятор (PD13) учун ҳолограмма видеолари ва қўлланма (`fan/README-uz.txt`).
- `downloads/Jarvis-Flash.zip` — флешка пакети: дастур, ишга туширгичлар (Windows/Mac/Linux), видеолар, қўлланма.
- `tools/` — видео, иконка ва флешка пакетини қайта ясовчи скриптлар.

**Муҳим:** 3D вентилятор дастур ишлатмайди ва эшитмайди, у фақат TF картадаги тайёр видеони кўрсатади.
Овозли ёрдамчи телефон/компьютерда ишлайди, вентиляторга эса ядро видеоси ўтказилади (`fan/README-uz.txt`).

**Фақат эгасига бўйсуниш:** биринчи ишга туширишда исм ва махфий ибора ёки рақамли PIN киритилади
(PBKDF2 ҳэш). Овоз билан очиш: «Жарвис, бир икки уч тўрт». Автоқулф, 5 хатодан кейин 30 сония кутиш.
Бу овоз шахсини аниқлаш эмас, парол иборага асосланган қулф.

**Имкониятлар:** 3D зарра ҳолограмма (10 шакл, шоу режими, вентилятор режими), соат/сана, об-ҳаво,
намоз вақти, валюта курси, Википедия, калькулятор, таймер, уйғотгич, секундомер, ёзувлар,
шахсий хотира («билиб қўй …»), сайтлар, қидирув. Тиллар: ўзбекча, русча, инглизча.
Созламаларга Claude API калити киритилса, ҳар қандай саволга жавоб беради (калит фақат браузерда сақланади).

**Илова каби ўрнатиш (PWA):** https орқали очиб, Chrome менюсидан «Ўрнатиш / Ҳозирги экранга қўшиш»ни танланг.
Ўрнатилган илова ўзи янгиланади: ҳар очилганда янги версия борлигини текширади (`jarvis/version.json`) ва
юқорида «Янгилаш» хабарини чиқаради. Янги версия чиқариш: `python3 tools/release.py 2.2.0`, сўнг commit ва push.
Овоз билан бирга: «овозни текшир» (диагностика), «янгиланиш бор», «брифинг», «вазифа қўш …», «ойимга қўнғироқ қил»,
«Тошкентга йўл кўрсат», «10 километр неча миль», «200 нинг 15 фоизи».
