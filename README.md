## Жарвис — овозли ёрдамчи

`jarvis/index.html` — битта файлли овозли ёрдамчи (ўрнатиш шарт эмас).

**Ишга тушириш:** файлни Chrome ёки Edge'да очинг, микрофон тугмасини босинг ва гапиринг.
Телефонда ишлатиш учун GitHub Pages'ни ёқинг (Settings → Pages) ва `…/jarvis/` манзилини очинг.

**Имкониятлар:** соат/сана, об-ҳаво, сайтларни очиш, Google/YouTube'да қидириш, калькулятор,
таймер, ҳазил. Тиллар: ўзбекча, русча, инглизча. Созламаларга Claude API калитини киритсангиз,
ҳар қандай саволга ақлли жавоб беради (калит фақат браузерда сақланади).
