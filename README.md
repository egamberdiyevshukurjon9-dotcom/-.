## Жарвис — ҳолограф овозли ёрдамчи

`jarvis/index.html` — битта файлли, ташқи кутубхонасиз овозли ёрдамчи (ўрнатиш шарт эмас).

**Ишга тушириш:** файлни Chrome ёки Edge'да очинг, микрофон тугмасини босиб гапиринг.
Телефонда ишлатиш учун GitHub Pages'ни ёқинг (Settings → Pages) ва `…/jarvis/` манзилини очинг.

**3D ҳолограмма** (соф WebGL): Жарвис ядроси, Ер, куб, пирамида, тор, ДНК, юрак, атом, галактика, Сатурн.
Ҳолограмма овоз ва ҳолатга (тингламоқда / ўйламоқда / гапирмоқда / қулфланган) жавоб беради,
суҳбат мавзусига қараб шакли ўзгаради. Сичқонча/бармоқ билан айлантириш, ғилдирак билан яқинлаштириш,
икки марта босиш — кейинги шакл.

**Фақат эгасига бўйсуниш:** биринчи ишга туширишда исм ва махфий ибора киритилади (PBKDF2 ҳэш, очиқ
сақланмайди). Кейин Жарвис қулфланган бошланади, паролни овоз билан ёки ёзиб айтганда очилади,
«қулфла» дейилса ёки автоқулф (2–30 дақиқа) ишласа яна қулфланади. 5 та хато уринишдан кейин 30 сония кутилади.
Эслатма: бу овоз *шахсини* аниқлаш эмас, парол иборага асосланган қулф.

**Имкониятлар:** соат/сана, об-ҳаво, доллар/евро/рубл курси, Википедия («… ким», «who is …»), калькулятор,
таймер ва эслатма, ёзувлар, батарея, сайтларни очиш, Google/YouTube қидирув, ҳазил ва қизиқарли фактлар,
ҳолограмма ранги/айланиши/ўлчами. Тиллар: ўзбекча, русча, инглизча. Созламаларга Claude API калитини
киритсангиз, ҳар қандай саволга жавоб беради ва ҳолограммани ўзи танлайди (калит фақат браузерда сақланади).
